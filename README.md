Vengo del mundo de los negocios y hoy aplico ese enfoque al análisis de datos para convertir información en decisiones accionables.
Tengo experiencia en administración, ventas y gestión de pequeños negocios, lo que me permitió desarrollar una fuerte orientación comercial y analítica. Actualmente me formo como Data Analyst en TripleTen, donde he trabajado en proyectos prácticos utilizando Python y SQL para limpieza y análisis de datos, EDA, análisis de KPIs y visualización de datos para identificar patrones e insights.

Me caracterizo por un pensamiento analítico estructurado, atención al detalle y la capacidad de comunicar resultados de forma clara a perfiles no técnicos. Mi background en negocio me permite entender los objetivos comerciales detrás de los datos.

## Proyectos Técnicos

### Proyectos principales

#### [Análisis de marketing, rendimiento y rentabilidad](Proyecto%20principales/An%C3%A1lisis%20de%20marketing%2C%20rendimiento%20y%20rentabilidad/README.md)

- **Descripción:** Análisis de visitas, ventas y gasto publicitario de un servicio digital, con métricas de uso, conversión por cohorte y canal, LTV, CAC y ROMI según las definiciones del notebook.
- **Resultados:** Se observaron aproximadamente **252,057** unidades monetarias de ingresos frente a **329,132** de gasto de marketing. El **75 % de los compradores** realizó su primera compra dentro de los dos primeros días desde su primera visita.
- **Habilidades técnicas:** Python · Pandas · NumPy · Matplotlib · Seaborn · Análisis de cohortes · KPIs de marketing.

#### [CallMeMaybe: detección de operadores ineficaces](Proyecto%20principales/CallMeMaybe%20Detecci%C3%B3n%20de%20Operadores%20Ineficaces/README.md)

- **Descripción:** Evaluación del desempeño de operadores de telefonía virtual mediante llamadas perdidas, tiempos de espera, actividad saliente y criterios por percentiles; incluye pruebas estadísticas.
- **Resultados:** El **45.6 %** de los operadores se clasificó con algún nivel de desempeño inferior al esperado según los criterios definidos en el proyecto. Se desarrolló un tablero para consultar los indicadores.
- **Habilidades técnicas:** Python · Pandas · NumPy · SciPy · Matplotlib · Seaborn · Tableau · Estadística inferencial.
- **Dashboard:** [Ver en Tableau Public](https://public.tableau.com/views/DASH_17870968103470/Dashboard1?:language=es-ES&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link).

#### [Análisis de una base de datos de libros con SQL](Proyecto%20principales/Proyecto_SQL_An%C3%A1lisis_Base_Datos_Libros/README.md)

- **Descripción:** Consultas sobre una base de datos PostgreSQL para analizar libros, autores, editoriales, calificaciones y reseñas.
- **Resultados:** **819 de 1,000 libros (81.9 %)** fueron publicados después del 1 de enero de 2000; se observaron **2.79 reseñas por libro** en promedio.
- **Habilidades técnicas:** SQL · PostgreSQL · Python · Pandas · SQLAlchemy · Análisis de datos relacionales.
- **Nota de acceso:** El notebook incluye resultados guardados; volver a ejecutar las consultas requiere acceso autorizado a una base PostgreSQL compatible.

#### [Evaluación de una prueba A/B: sistema de recomendaciones](Proyecto%20principales/Test%20A-B/README.md)

- **Descripción:** Validación de la población experimental, construcción de una cohorte con 14 días completos de observación y contraste de tasas de conversión entre los grupos A y B.
- **Resultados:** La cohorte analítica incluyó **1,419 usuarios**. Ninguno de los tres eventos evaluados alcanzó el incremento relativo del **10 %** planteado; las pruebas unilaterales no aportaron evidencia estadísticamente significativa de una mejora de B.
- **Habilidades técnicas:** Python · Pandas · NumPy · Matplotlib · Statsmodels · Pruebas de hipótesis · Análisis de experimentos.

### Otros Proyectos

#### [Análisis de carrito de compra de Instacart](Otros%20Proyectos/An%C3%A1lisis%20de%20carrito%20de%20compra%20de%20Instacart/README.md)

- **Descripción:** Análisis exploratorio de pedidos, productos y hábitos de recompra para identificar patrones de consumo.
- **Resultados:** La mayor actividad de pedidos se observó entre las **10:00 a. m. y las 4:00 p. m.**, especialmente domingos y lunes; se identificaron patrones de recompra de productos frescos y orgánicos.
- **Habilidades técnicas:** Python · Pandas · NumPy · Matplotlib · Seaborn · Limpieza y exploración de datos.

#### [Análisis de rentabilidad de tarifas de prepago en Megaline](Otros%20Proyectos/An%C3%A1lisis%20de%20rentabilidad%20de%20tarifas%20de%20prepago%20en%20Megaline/README.md)

- **Descripción:** Comparación del uso de llamadas, mensajes y datos móviles y de los ingresos generados por los planes Surf y Ultimate.
- **Resultados:** El README del proyecto identifica **mayores ingresos totales en Surf** y **mayor ingreso promedio por cliente en Ultimate**, así como diferencias en la variabilidad de los ingresos.
- **Habilidades técnicas:** Python · Pandas · NumPy · Matplotlib · Seaborn · Análisis descriptivo.

#### [Aplicación de ventas de autos](Otros%20Proyectos/Aplicaci%C3%B3n%20de%20ventas%20de%20autos/README.md)

- **Descripción:** Aplicación en Streamlit para explorar anuncios de vehículos mediante histogramas, filtros y un gráfico de dispersión de precio frente a kilometraje.
- **Resultado:** Visualización interactiva de los datos para facilitar su exploración sin necesidad de ejecutar el análisis en un notebook.
- **Habilidades técnicas:** Python · Pandas · Streamlit · Plotly Express.
- **Aplicación:** [Abrir aplicación web](https://car-sales-app-wag5.onrender.com/).

#### [Simulador de probabilidad de lanzamiento de moneda](Otros%20Proyectos/Simulador%20de%20probabilidad%20de%20lanzamiento%20de%20moneda/README.md)

- **Descripción:** Aplicación en Streamlit que simula lanzamientos de una moneda con distribución de Bernoulli, muestra la media acumulada y registra experimentos.
- **Resultado:** Visualización de la convergencia de la media acumulada hacia el valor esperado **0.5** al aumentar el número de lanzamientos.
- **Habilidades técnicas:** Python · Streamlit · Pandas · SciPy · Probabilidad · Simulación.
